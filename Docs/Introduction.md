In today’s digital age, users have multiple online accounts, each requiring secure and unique passwords. However, remembering different passwords is difficult, leading users to reuse the same weak passwords across multiple sites. This increases the risk of hacking and data breaches. Our project, “Password Manager System,” solves this problem by securely storing and managing passwords.

The main objectives of this project are:

To provide a secure login and registration system for users using email and password.

To implement OTP-based verification for enhanced security.

To provide a strong password generation tool to help users create secure credentials.

To store passwords in a secure database and display them to users in a masked format.

To allow users to copy passwords easily while keeping them protected.

The scope of the system includes login/registration with email verification, a dashboard to save website credentials, a password generator, and a page to view and copy saved passwords. Each feature has been carefully designed with a focus on simplicity, security, and user-friendliness.

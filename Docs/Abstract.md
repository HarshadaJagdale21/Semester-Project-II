                                           Abstract 

•Title: 
     Secure Password Manager with Strong Password Generation and Permanent Storage

•Domain:
     Web Development

•Application:
     Password Management and Secure Data Storage
 
•Expected Algorithm / Processing:
    The project uses an algorithm that randomly selects characters from distinct sets—lowercase, uppercase, numbers, and symbols to generate strong passwords. User input is processed on the     client-side using JavaScript, and data is then transmitted by Node.js server built with Express. The server handles saving and retrieving password data from a MySQL database, ensuring permanent storage. The application updates the user interface in real-time to display all saved passwords upon page load or refresh.

•Expected Output from Project: 
An interactive and user-friendly web interface that allows users to generate, save, and view strong passwords stored in a MySQL database with immediate on-screen display upon each visit.

•Abstract:
This project presents a comprehensive Password Manager designed to enabling users to generate robust passwords and store them permanently. The system integrates a front-end built with HTML, CSS, and JavaScript, which offers a clean and attractive interface for password management. Users can generate strong, randomized passwords that include a mix of uppercase and lowercase letters, numbers, and special symbols. These passwords, along with associated website and user details, are transmitted securely to a Node.js server. The server, powered by Express and connected to a MySQL database, handles data storage and retrieval. This seamless integration ensures that all saved passwords are readily accessible and displayed on the web interface each time the application is launched. Overall, the project provides a practical solution for secure password management and demonstrates effective use of modern web development and database technologies.

i. Methodology / Approach

Followed the Agile development model for faster iterations.

Modules: Registration, Login, Dashboard, Password Generator, View/Edit/Delete Entries, Logout.

Used hashing for user passwords and session authentication.

ii. Materials, Tools, Software Required

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL (with phpMyAdmin)

Server: XAMPP (for local development)

Browser: Google Chrome / Firefox for testing
